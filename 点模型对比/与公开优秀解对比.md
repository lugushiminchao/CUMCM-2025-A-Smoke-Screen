## 4. 对比结论

1. **问题一高度一致**  
   公开解与我们都在 1.36–1.45 s。点中心略长于圆柱严格，符合几何直觉。

2. **问题二也高度一致**  
   单弹优化大致 **4.5–4.8 s**。我们点模型 4.81、圆柱 4.54，落在公开区间中部/偏上。

3. **问题三：我们圆柱 7.61 优于 Julia 的 6.41，接近/略低于 niceU 8.24 与 oox 7.40**  
   差异主要来自：是否严格全遮、采样密度、优化是否充分、是否允许不连续并集。

4. **问题四：严格全遮天然更难**  
   我们圆柱严格 **10.61** 低于多数“宽松/半遮”方案（11.7–15.5）。  
   点模型 **12.84** 更接近 Julia 11.72，仍低于 50% 阈值方案的 15.18。  
   这说明：**判据越严，可报时长越短**；不是优化失败的充分证据。

5. **问题五分歧最大**  
   - 我们圆柱 21.98 / 点 26.85  
   - niceU ≈20.5、oox 25.36 与我们同量级  
   - Julia 38.62 明显偏高，需怀疑目标是否为三导弹简单加总、是否更松判据、或约束处理不同  
   我们 Q5 分导弹：圆柱 M1≈7.61、M2≈10.65、M3≈3.72，总和≈21.98，结构合理。

6. **与“优秀论文”应对齐的建模口径**  
   省级一等奖仓强调：圆柱特征点 + 高精度时间边界。我们的**圆柱严格全遮蔽**更接近“保守/物理可辩护”的优秀论文口径；点模型适合快速优化与上界估计。

## 5. 使用建议

- 写论文主结果：优先报 **圆柱严格**（Q1–Q5：1.36 / 4.54 / 7.61 / 10.61 / 21.98）。
- 附录可附 **点模型** 作为宽松上界与速度对照。
- 与公开数字对比时，务必注明对方是“中心点 / 50% 采样 / 严格全遮”，避免被误读为“我们更差/更好”。
