## 模型要点

- 判据：烟幕球心到导弹—真目标中心视线**线段**距离 ≤ 10 m
- 云团：起爆后存活 20 s，以 3 m/s 匀速下沉
- 三枚有效遮蔽取**并集**（可不连续）
- 决策变量：共用航向 θ、速度 v；每弹投放时刻 t_i、引信延时 τ_i
- 优化：GPU 上批量评估数万候选 → Top-K 坐标轮换精修 → 边界二分定稿时长
